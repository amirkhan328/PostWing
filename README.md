🚀PostWing - All-in-One Social Media Manager

PostWing is a powerful social media management app designed to help creators, businesses, and marketers publish and manage content across **Facebook, Instagram, TikTok, and YouTube** from a single dashboard.

### ✨ Key Features
- 📅 **One-Click Publishing:** Post to all platforms at once.
- ⏰ **Smart Scheduling:** Schedule your posts for the best time.
- 📊 **Analytics Dashboard:** Track performance in one place.
- 🤖 **AI-Powered Captions:** Generate engaging captions.
- 🔒 **Secure & Fast:** Built with Next.js and modern APIs.

### 🛠️ Tech Stack
- Next.js, TypeScript, Tailwind CSS
- Facebook Graph API, Instagram API, TikTok API, YouTube API

### 🎯 Vision
To make social media management simple, fast, and powerful for everyone.
